# Python Calculator 🧮

This is a simple calculator program I made using Python. It can perform different operations on two numbers and allows the user to continue calculating.

## What It Does

* Addition
* Subtraction
* Multiplication
* Division
* Average of two numbers
* Allows the user to perform multiple calculations
* Handles invalid number input

## What I Used

* Python
* Functions
* `while` loop
* `if`, `elif`, and `else`
* `try/except`
* User input

## How to Run

Make sure Python is installed on your computer.

Open the project folder in the terminal and run:

```bash
python calculator.py
```

## Example

```text
Please Select an Operation
1. Addition
2. Subtraction
3. Multiply
4. Divide
5. Average

Please select 1,2,3,4,5: 1
Put 1st Number: 10
Put 2nd Number: 5

10 + 5 = 15

Continue (y/n): y
```
